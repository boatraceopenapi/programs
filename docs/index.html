Boatrace Open
API for Programs

ボートレースの出走表データを JSON 形式で配信する非公式 API です。 GitHub Actions が約 3 時間おきにデータを更新して GitHub Pages 上でホストしています。

本日の出走表を見る (v3) GitHub リポジトリ
⚠ Deprecated

本リポジトリ（Boatrace Open API for Programs）は 今後の利用が推奨されません。 今後は後継リポジトリの boatraceopenapi/api をご利用ください。

ℹ️ なお、非推奨ではありますがデータ更新・API 配信自体は引き続き稼働しています。 既存の利用箇所を直ちに移行する必要はなく、現状のまま継続してご利用いただくことも可能です。 ただし将来的に更新が停止される可能性もあるため、可能な範囲で後継 API への移行をご検討ください。

エンドポイント

GET / JSON

日付は日本標準時 JST（UTC+9）基準。データが存在しない日付を指定した場合は HTTP 404 が返されます。

v3 2023年05月01日以降
https://boatraceopenapi.github.io/programs/v3/YYYY/YYYYMMDD.json
v2 2025年05月01日以降
https://boatraceopenapi.github.io/programs/v2/YYYY/YYYYMMDD.json

サンプル

  • 本日の出走表（v3） /v3/today.json
  • 2025年05月01日の出走表（v3） /v3/2025/20250501.json
  • 本日の出走表（v2） /v2/today.json
  • 2025年05月01日の出走表（v2） /v2/2025/20250501.json

注意事項

  • 非公式です。BOATRACE 公式サイトおよび関連団体とは一切関係ありません。

  • リアルタイムではありません。GitHub Actions による約 3 時間間隔の定期更新のため、反映まで数分〜数時間の遅れが生じる場合があります。

  • 正確性・完全性は保証していません。収集・変換の都合により、欠損や誤りが含まれる可能性があります。

  • 公式情報が必要な場合は、必ず BOATRACE 公式サイトをご確認ください。

  • 利用は自己責任でお願いします。
